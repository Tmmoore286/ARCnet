    # Risk, Ethics, and Compliance (Unclassified)

    Key Risks
    - Data Delays or Gaps: mitigated with synthetic/derived data; mark provenance.
    - Token/Cost Growth: strict budgets; K caps; caching; multi‑pass (Draft→Judge→Finalize).
    - Bias/Echo Chambers: diversity penalties; dissent capture; policy must‑include coverage.
    - Adoption & Trust: explainable checkpoints; evidence citations; commander HITL.

    Ethical Principles (DoD AI)
    - Responsible: human‑in‑the‑loop by default; clear override controls.
    - Equitable: MOS‑scoped doctrine; avoid leakage across roles; fairness checks in selection.
    - Traceable: citations, logs, and seed status; JSONL audit trail.
    - Reliable: bounded prompts/models; fallback modes; robust error handling.
    - Governable: feature flags; kill‑switch for Mesh; configuration under command control.

    Compliance & Security
    - Unclassified only; no PII; redaction before ingest; classification fields on outputs.
    - Access via G‑3/G‑4/G‑8 approvals; least privilege; read‑only snapshots where possible.
    - Publication: remove any sensitive details; publishable paper remains unclassified.

# USMC Organization Pack (Org Baseline for the App)

This pack provides **doctrinal, public, approximate** org templates for your unit selector. Replace with TFSMS exports when possible.

## Structure
- `Services/org_templates/*.json` — MEF, Division, Battalion, MEU templates (+ schema file).
- `Services/Gshop_specialists.csv|json` — G-section specialists and agent templates.
- `References/usmc_org_references.csv` — key manuals and links.
- Download scripts for PDFs in `References/`.

Fields marked `"approximate": true` are derived from doctrine (not TFSMS). Each node includes a `provenance` block for traceability.

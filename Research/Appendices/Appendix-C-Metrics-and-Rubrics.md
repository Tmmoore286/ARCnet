# Appendix C — Metrics & Rubrics (Unclassified)

Handshake Strength (0–1)
- Coverage (0.4): % of claims with citations (docId/section).
- Corroboration (0.2): avg unique sources per claim.
- Specificity (0.2): direct quotes/sections vs generic refs.
- Compliance (0.2): classification/ROE conformance; redactions present.

Usefulness (1–5 Likert)
- Clarity, Actionability, Constraint Adherence, Risks/Tradeoffs, Evidence Quality.

COA Quality Rubric
- Feasibility, TEEP Impact (none/offsets), Resource Realism, Risk Awareness, Measurable Readiness Delta.

Latency Targets
- Status first checkpoint ≤ 5s; Org planning ≤ 20s; Mesh planning ≤ 40s.

Token Budgets
- Specialist prompt ≤ 800 in / ≤ 300 out; Aggregator ≤ 600 total.

# DEV::Agent Workflow

Non-shipping development automation lives here and is excluded from Xcode targets.

Suggested layout:
- `plans/` — short, incremental plans/state (json)
- `playbooks/` — task recipes (md)
- `prompts/` — reusable prompts for dev agents (md)
- `scripts/` — helper scripts (no secrets)

See AGENTS.md §4 and CODEX.md §2.1.
